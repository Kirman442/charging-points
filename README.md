# Ladeinfrastruktur in Deutschland

Interaktive Karte öffentlicher Ladeinfrastruktur in Deutschland mit regionalen
Auswertungen und einem experimentellen Autobahnmodus für A1–A9.

[Anwendung öffnen](https://kirman442.github.io/charging-points/)

React, Vite, deck.gl und MapLibre. Lokal starten: `npm ci`, danach `npm run dev`.
Quellen, Datenstände und Lizenzhinweise stehen in der Anwendung.
