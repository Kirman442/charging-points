Распаковать архив в корень проекта `charging-points`. Файл Германии оставляем там, где скачан: `M:\projekte\Ladesaeulenregister\data\germany-latest.osm.pbf`. Не распаковывать PBF и не отправлять все 4,5 ГБ в чат.

## Запуск из CMD / PowerShell

Открыть терминал в `M:\projekte\Ladesaeulenregister\charging-points`.

```bat
py -3.12 -m venv .venv-pbf
.venv-pbf\Scripts\python.exe -m pip install -r scripts\requirements-pbf.txt
.venv-pbf\Scripts\python.exe scripts\extract_pbf_networks.py --pbf "M:\projekte\Ladesaeulenregister\data\germany-latest.osm.pbf" --routes A1 A9
```

Если установленный Python запускается командой `python`, первая команда может быть `python -m venv .venv-pbf`. Нужен Python 3.10 или новее с доступными колёсами зависимостей. Активация окружения не нужна.

Не менять имя файла в команде на `.crdownload`: нужен окончательно скачанный `.osm.pbf`. Если браузер сохранил файл под другим именем, указать его точное имя в `--pbf`.

## Что делает скрипт

- Читает геометрию направлений A1/A9 из существующих пилотных Parquet проекта. Это ориентир для извлечения, а не заново подтверждённая геометрия направлений.
- Из локального PBF выбирает дорожные ways, пересекающие коридор 20 км вокруг этих геометрий. A1 остаётся двумя раздельными участками. Буфер — запас для диагностики, не предел допуска площадки.
- Сохраняет motorway, motorway_link и остальные классы дорог, используемые моделью. Footway, path, cycleway и другие классы, не поддерживаемые текущей автомобильной моделью, не входят в основной набор; недоступность площадки из этого факта не следует.
- Не удаляет дороги из-за `access`, `private`, `oneway`, условных ограничений или шлагбаумов. Сохраняет теги для последующего расчёта.
- Дополняет участников ограничений поворотов, включая via-way. Если добавленные дороги приносят дополнительные ограничения, замыкает выборку и по ним. При отсутствующем участнике, повреждении PBF или незавершённом замыкании останавливается с ошибкой.
- Записывает SHA-256 исходного PBF, время среза из заголовка при наличии, число объектов и результаты проверки ссылок.
- Сохраняет JSON и упаковывает результаты в ZIP. Исходный PBF и текущие файлы карты не изменяет.

Направления выгружаются вместе, но при следующем анализе проверяются отдельно. Этот шаг НЕ пересчитывает площадки, интервалы или соответствие AFIR. На реальной полной Германии в текущем окружении скрипт не запускался; интеграционные проверки выполнены на небольшом PBF в Linux. Время обработки и размер результата зависят от диска и данных.

## Ресурсы и сообщения

Подготовить ориентировочно 20–30 ГБ свободного места на диске проекта для временного дискового кэша, SQLite и результатов. Это запас, не точно измеренное требование для твоего файла. Кэш удаляется после завершения или обработанной ошибки. Принудительное закрытие процесса может оставить папку `pbf-work-*`.

Первые сообщения: чтение SHA-256, затем первый проход по PBF. Далее выводится прогресс через каждые 100 000 дорожных ways. При заполнении кэша узлами до первого way некоторое время новых сообщений не будет. Это локальная обработка, интернет после установки зависимостей не требуется.

Если на диске проекта мало места, выбрать другой диск для временных файлов:

```bat
.venv-pbf\Scripts\python.exe scripts\extract_pbf_networks.py --pbf "M:\projekte\Ladesaeulenregister\data\germany-latest.osm.pbf" --routes A1 A9 --work-dir "D:\pbf-work"
```

Выходная папка по умолчанию `data_sources\pbf_networks`. Скрипт отказывается заменять уже существующую папку. Для повторного запуска указать новую, например `--output data_sources\pbf_networks_retry`.

## Что прислать

После строки `Done` взять:

```text
data_sources\pbf_networks\road-networks-a1-a9.zip
```

Пришли этот архив для анализа A1/A9. Если архив окажется слишком большим для загрузки в чат, сначала пришли два маленьких файла `a1\pbf-extraction-audit.json` и `a9\pbf-extraction-audit.json` и размер ZIP; выберем способ передачи. Исходную Германию повторно передавать не требуется.

При ошибке пришли текст вывода. Не использовать `.part` как готовый результат.


Проверены сохранение тегов, изоляция двух коридоров, дорога с обоими концами за границей коридора, полный набор узлов, замыкание ограничений за границей, via-way, сохранение разрыва A1, отказ от перезаписи результата и обработка повреждённого PBF.
