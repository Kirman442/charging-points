# 34_step: исправление служебного отчёта А5

Распаковать с объединением папок в `M:\projekte\Ladesaeulenregister\charging-points`.
Запустить `34_step_repair_a5_full_review.cmd`. Нужны установленные скрипты шага 33 и сохранённая папка `M:\projekte\Ladesaeulenregister\data\33_step_a5_full_entry_review` вместе с `network`.

PBF не читается. Проверяются контрольные суммы исходных файлов и готовой сети. Исправляется подпись направления северных участков в audit.json. Затем по сохранённой сети повторяется только последний участок к Basel (400–440,47 км), где из отчёта выпала неподтверждённая площадка 4310 (44 кВт, без DC ≥150 кВт).

У конечной точки принимается погрешность километража до 1 мм: расчёты проекции/длины на разных платформах могут немного отличаться. Внутренние границы по-прежнему полуоткрытые, чтобы не дублировать площадки. Если пропуск не объясняется этим условием, скрипт останавливается и требует диагностики, не дописывает статус автоматически. Соответствие полного списка исходному пилоту проверяется после объединения результатов.

Исходные файлы шага 33 не изменяются. Результаты создаются в `M:\projekte\Ladesaeulenregister\data\34_step_a5_full_entry_review`.
Прислать **34-a5-full-entry-review-results.zip** из этой папки. Карта, мощности, критерии и интервалы не меняются. Новые въезды автоматически не подтверждаются.
