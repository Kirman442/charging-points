# Итог: доступность по дорожной модели A5/A1/A9

Пользователь принял воспроизведённые собственные дорожные связи площадок как
основу выпуска. Условия: подъезд ≤3 км, возврат на своё направление ≤3 км,
строгая ближайшая дорога ≤60 м. Для интервалов нужны ≥400 кВт суммарной
мощности установок и хотя бы одна DC-точка ≥150 кВт.

Проверка каждого фактического въезда — отдельная задача, не блокирующая выпуск
модели. Отсутствие фотографии не отменяет найденный модельный маршрут.
Соседние OSM-кандидаты не создают связь площадки. Отклонённый кандидат не
отменяет её собственную связь. Их полный разбор остаётся в очереди шага 36.

Из готовых данных шага 35 добавлены только условия собственных путей к
координате реестра: `access_conditions_json`, `access_evidence_checked`,
`registry_site_id`. Условия путей к соседним зарядкам в карту не переносятся.
Шлагбаум, customers/permissive и условные теги показываются отдельно в карточке;
они не изменяют статус маршрута, мощность, участие в интервалах или видимость.
Отсутствие отмеченных тегов не означает подтверждённый свободный въезд.

`scripts/finalize_motorway_model.py` проверяет совпадение текущих активов с
исходными хэшами шагов 34/35, собственные связи, покрытие кандидатов, экспорт
ZSTD-10, точное сохранение всех старых колонок и формулу каждого известного
интервала. Это лёгкая обработка готовых файлов, без PBF, графа или поиска.
Все три экспорта проверяются до замены активов. Исходные Parquet сохранены
в `data/38_step_road_model_release/before-release`.

Интервал = возврат предыдущей площадки + автобан от точки её возврата до
следующего съезда + подъезд следующей. Для площадок на одном съезде берётся
минимальная совместимая пара. Проверены 262 известных интервала; края и
несовместимые пары остаются неизвестными. A1 сохраняет две физические части
по два направления; через разрыв не создаются линия или интервал.
Чекбокс меняет показ кандидатов, не интервалов.

Готовые данные, код и новый декодер обновлять вместе. Старые журналы и отчёты
шагов 33–37 не переписываются. Их входные хэши относятся к прежним Parquet:
повторный запуск шага 35 на новой версии активов не нужен и будет отклонён.
Для проверки старого расчёта использовать сохранённый снимок входов.

Это воспроизводимая исследовательская модель, не проверка каждого физического
въезда и не заключение о соответствии AFIR.

## Уточнение интерфейса тестового сайта — 09.10.2026

Чекбокс «Режим автобана» находится над выбором трассы. При выключенном
режиме трасса и направление скрыты; последний выбор сохраняется до включения. В этом режиме земля
не фильтрует площадки, территории фиксируются на землях; оба списка недоступны.
После выключения восстанавливаются ранее выбранные земля и территории.

Квадрат — найден собственный маршрут и есть условия проезда легкового
автомобиля: доступ, барьер, размеры/масса, часы доступа или относящиеся к нему
условные теги. Цвет и обводка мощности сохранены; интервалы не изменяются.
Теги условной скорости, парковки, грузовиков и прочие дорожные сведения доступны
отдельно в карточке и сами по себе не делают маркер квадратным.

На A5 к Hattenbacher Dreieck 78 таких площадок. Прежние 106 в аудите выпуска —
число площадок с любыми сохранёнными условиями, включая прочие дорожные теги;
это не изменение дорожных связей. В карточке указан источник: готовые данные
OSM шага 35. Сохранённые условия объединяют подъезд и возврат; конкретная
сторона пути не приписывается. Часы доступа на дороге не равны часам зарядки.

Подробности площадки возвращают site_id для безопасного сопоставления
карточки с моделью. Данные Parquet и результаты расчётов не изменялись.
Для тестового просмотра: npm run build, затем npm run preview.
.gitignore не менялся; отчёты и снимки проверки находятся вне проекта,
в data/39_step_motorway_ui_review. Деплой загружает только dist.
