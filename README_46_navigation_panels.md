# 46_step_navigation_panels

База: dev, be4ec8f (объединённый дизайн и карточка мощности шага 43).

1. Карточки земель открываются сверху, включая повторный выбор той же земли.
   При возврате в обзор восстанавливается прокрутка рейтинга.
2. Выбор земли из рейтинга приближает карту и сохраняет исходный вид для
   возврата по «Все земли». Клик по карте не приближает землю.
   Ручное изменение фильтров или сброс отменяют сохранённый переход.
3. Четыре равные кнопки панелей с иконками и короткими подписями.
   Этот визуальный вариант подготовлен для совместного просмотра.
4. Шапка, кнопки, выбор слоя и настройки на компьютере имеют ширину 306 px,
   соответствующую прежней ширине шапки. Мобильная компоновка отдельная.
5. Нижние панели источников используют общий компактный стиль обеих тем.
6. «Как считаются показатели» находится внутри общей прокрутки аналитики
   и больше не вытесняет статистику в мобильной панели на половину экрана.
7. Для короткого горизонтального экрана настройки подняты и уплотнены:
   содержимое прокручивается, нижние кнопки остаются внутри экрана.
8. Нижняя часть мобильных настроек компактнее, основные кнопки стоят рядом.
9. Иконка мобильной легенды соответствует остальным кнопкам легенды.
10. Подсказки площадок и групп используют правильные русские склонения.

Проверки: 98 тестов Node; после последней правки повторно 10 целевых тестов,
ESLint и сборка. Браузер: тёмная и светлая темы, переход Bremen из рейтинга,
возврат к рейтингу, выбор и повторный выбор Bayern кликом по карте,
одинаковая ширина четырёх блоков, размеры 1440×900, 844×390 и 320×568.
Проверено раскрытие пояснений без схлопывания области статистики.
Сохраняется прежнее предупреждение сборки о крупных чанках.
