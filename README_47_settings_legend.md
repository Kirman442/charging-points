# Шаг 47 — настройки, активные фильтры и легенда

База: `df07ad1`, ветка `dev`. Изменения предназначены для локальной проверки.

## Изменения

1. Из заголовка настроек удалено «Ваша карта». Оставлены «НАСТРОЙКИ» и кнопка закрытия.
2. Заголовки `.panel-heading h2` и `.app-brand h1` используют `font-weight: 400`.
3. На широком экране активные фильтры расположены справа от настроек, от их верхнего края вниз. Добавление фильтров больше не смещает настройки. На телефоне сохранена горизонтальная прокручиваемая строка; на узком компьютере при открытых настройках эта строка скрывается, чтобы не перекрывать панель. Фильтры доступны внутри настроек.
4. Легенда остаётся открытой при изменении быстрого аналитического слоя и обновляет содержание. Открытие настроек сворачивает легенду. Если легенда открыта из настроек, закрытие возвращает настройки с выбранной вкладкой и значениями. Клик снаружи или начало перетаскивания закрывают легенду: при закрытых настройках жест сразу работает на карте; при временно скрытых настройках первый жест только возвращает их. Быстрый выбор показателя не закрывает легенду. На телефоне закрытие легенды восстанавливает предыдущее состояние информационной панели.

## Проверка

- 16 тестов настроек, навигации, выбранной площадки и оформления прошли.
- `npm run lint`, `npm run build`, `git diff --check` прошли. Сборка сообщает прежнее предупреждение о размере основного пакета.
- В браузере проверены тёмная и светлая темы, экраны 1440×900, 390×844 и 844×390.
- Проверены смена показателя при открытой легенде, закрытие кликом и перетаскиванием, возврат вкладки «Слои» и значений фильтров, отсутствие сдвига настроек и горизонтального переполнения.
- Скриншоты находятся в приложенной папке `proof`.
