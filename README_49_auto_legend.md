# Шаг 49 — автоматическое открытие легенды

База: `5beec77`, ветка `dev`.

При смене показателя через быстрый список легенда автоматически открывается, если панель настроек закрыта. Правило действует для всех вариантов, включая зарядные площадки. Уже открытая легенда сохраняется и обновляет содержание. При открытых настройках автоматического открытия нет. Переключение темы не открывает легенду.

На телефоне открытие временно скрывает информационную панель, а закрытие легенды восстанавливает её предыдущее состояние. Сохраняются закрытие кликом по карте, перетаскиванием и вручную; после ручного закрытия выбор другого показателя снова открывает легенду.

Проверены в браузере первоначальное отсутствие легенды, автоматическое открытие, обновление нескольких показателей, выбор зарядных площадок, повторное открытие после ручного закрытия, исключение при открытых настройках, обе темы и телефон 390×844. Проверен возврат информационной панели на телефоне. Линтер, сборка и `git diff --check` прошли; предупреждение сборки о размере пакета осталось прежним.

`project` содержит изменённые файлы, `before` — предыдущие версии, `changes.patch` — патч, `manifest.json` — контрольные суммы, `proof` — скриншоты. Push и публикация не выполнялись.
