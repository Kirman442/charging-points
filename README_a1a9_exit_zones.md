# 30_step — A1 и A9: проверка от всех съездов

Распаковать обновление в корень `charging-points` с заменой файлов.
Готовые Parquet уже рассчитаны: для просмотра достаточно запустить приложение.
Повторно скачивать PBF или запускать экстракцию не нужно.

## Что считается

Каждое направление анализируется независимо. Начало подъезда — реальное
ответвление дорожного графа от выбранной проезжей части. Тег
`highway=motorway_junction` помогает назвать съезд, но не является обязательным:
учитываются промежуточные ответвления и дороги к площадкам отдыха.
В подъездной сети допускаются другие автобаны с сохранением направления движения.

Площадка получает статус найденного маршрута только при подъезде ≤3000 м,
возврате ≤3000 м на то же направление и привязке к ближайшей дороге ≤60 м.
Учитываются одностороннее движение, ограничения доступа, барьеры и повороты.
Неразобранные сложные или условные ограничения исключаются консервативно.
Найденный маршрут ведёт к дороге рядом с координатой; фактический въезд
на зарядную площадку этим не подтверждён.

В интервалах участвуют только площадки с найденным маршрутом, суммарной мощностью
≥400 кВт и хотя бы одной DC-точкой ≥150 кВт. Интервал включает возврат предыдущей
площадки, путь по автобану до следующего съезда и следующий подъезд.
При несовместимых съезде и возврате интервал неизвестен. У A1 два физических
участка: разрыв в Эйфеле не соединяется и не превращается в интервал.

Кандидаты формируются в геометрическом коридоре 3,5 км, затем проверяются по дорогам.
Длинный подъезд исключается только если и диагностический поиск без проверок
доступа и поворотов даёт расстояние больше 3 км. Если путь не установлен,
площадка остаётся для проверки. Диагностика с пределом 15 км и привязкой 200 м
никогда не подтверждает маршрут. Исключение относится к модели OSM, а не
доказывает отсутствие короткого подъезда на местности.

Подъезд ≤3 км предусмотрен AFIR; возврат ≤3 км и привязка ≤60 м — условия пилота.
Срез зарядок — 2026-09-01. Это исследовательская оценка, не заключение о соответствии AFIR.

## Сеть и воспроизводимость

Используется полученная пользователем выгрузка Germany PBF со временем
2026-10-06T20:21:06Z. Данные восстановления и ограничения полноты записаны
в `source_audit` отчётов `data_sources/a1/pilot-3km-audit.json` и
`data_sources/a9/pilot-3km-audit.json`.
Первоначальный SHA-256 источника старой SQLite не сохранялся; восстановление
проверило 256 объектов по исходному PBF. Этот предел проверки сохранён в отчёте.

Пять неполных ограничений A1 не игнорируются: участвующие дороги блокируются
в строгом графе. Перед экспортом проверяются все ID дорог найденных подъездов
и возвратов: они не должны пересекаться с заблокированными участниками.

Большой JSON читается потоком в пространственный SQLite-индекс. Для поиска
площадки группируются по квадратам 30 км. Окно поиска охватывает их координаты
с запасом 16 км с каждой стороны; ранее сохранённые квадраты могут иметь более
широкое окно. Этот запас содержит
любой проверяемый дорожный путь до 15 км от площадки и привязку до 200 м.
Дороги берутся целиком; относящиеся к ним ограничения сохраняются. Все узлы
основного маршрута остаются возможными началами/концами подъезда и возврата.
Служебный список съездов охватывает окна кандидатов, а не является отдельным
полным реестром всех развязок Германии.

Результаты каждого квадрата сохраняются и используются при повторном запуске.
Контрольные суммы сети, файла площадок, файла мощностей и маршрутов защищают
от применения старого кэша к другим исходным данным. Файлы зарядок также
проверяются по runtime-каталогу. Сменив JSON, укажите новый путь SQLite и уберите
старые `exit-zone-checkpoints` либо сохраните их отдельно.

Для повторного расчёта в Windows, из корня проекта:

```bat
.venv-pbf\Scripts\python.exe -m pip install -r scripts\requirements-a9.txt
.venv-pbf\Scripts\python.exe scripts\refresh_autobahn_access.py --route A1 --network data_sources\pbf_networks\a1\access-network.json --index data_sources\road-analysis-cache\a1.sqlite
.venv-pbf\Scripts\python.exe scripts\refresh_autobahn_access.py --route A9 --network data_sources\pbf_networks\a9\access-network.json --index data_sources\road-analysis-cache\a9.sqlite
```

Рядом с каждым `access-network.json` должен лежать его `pbf-extraction-audit.json`.
Для основного пути используются ранее проверенные маршруты; каждое их направленное
ребро сверяется с новой сетью. При изменении топологии программа останавливается,
вместо автоматического соединения разрывов.

Полные результаты: `exit-zones.json`, сводка `pilot-3km-audit.json` и таблица
`pilot-3km-site-review.csv`. ID дорог подъезда/возврата сохранены для ручного разбора.
Сетевые JSON, SQLite и промежуточные квадраты не нужны приложению в браузере.

A5 в этом обновлении не пересчитывается.
