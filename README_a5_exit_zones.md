# A5: дорожные зоны всех разрешённых ответвлений

Эксперимент применяется только к A5. Установить поверх `charging-points-a5-3km-update.zip` с заменой перечисленных файлов. A1/A9 используют прежние данные и отбор. Восстановление исходной версии A5: вернуть `public/data/autobahn_a5_zstd10.parquet`, `src/data/autobahn.js`, `src/components/AutobahnPanel.jsx` из предыдущего обновления вместе.

## Что изменено

Направления проверяются последовательно и независимо. Для каждого направления берётся его проезжая часть и все разрешённые переходы с неё на подъездную сеть, а не только именованные развязки. Поэтому учитываются площадки отдыха и ответвления без `motorway_junction`. Ограничения движения, доступа, барьеров и поворотов сохраняются. Служебный проезд `access=no, emergency=yes` не становится обычным съездом.

Другие автобаны теперь участвуют в подъездных путях (например, A661). Их направление и ограничения сохраняются; выбранная основная проезжая часть A5 исключена из подъездного графа. Начало пути — реальная точка отделения от выбранной проезжей части, а не условная точка на карте.

Поиск от всех съездов реализован как поиск кратчайших путей с несколькими источниками: дорожные зоны объединяются, для площадки сохраняется съезд найденного подходящего пути. Это не присвоение площадки ближайшему по прямой съезду. Возврат рассчитывается отдельно на то же выбранное направление A5.

Начальный коридор ≤3,5 км по прямой остаётся только предварительной выборкой. Нет правила исключать зарядку «после съезда» или «перед следующим съездом» по продольному километражу. Решение принимается по дорожному маршруту.

## Три группы площадок

1. **Маршрут в пределах пилота:** подъезд ≤3 км, возврат ≤3 км, привязка ≤60 м; показывается сразу. В интервалах участвуют только такие площадки с суммарной номинальной мощностью ≥400 кВт и DC-точкой ≥150 кВт.
2. **Длинный подъезд по модели OSM:** даже диагностическая сеть без проверок доступа, барьеров и поворотов не даёт подходящего подъезда ≤3 км, но находит более длинный. Такие площадки исключены из основного списка и карты, включая режим чекбокса. Они сохранены в CSV и JSON.
3. **Требует проверки:** отсутствует разрешённый короткий путь или возврат, неоднозначны ограничения/барьеры/привязка, либо путь не найден и в диагностике. Эти случаи остаются под чекбоксом «Показать площадки, требующие проверки».

Диагностическая сеть сохраняет направления движения, но снимает проверки доступа, барьеров и поворотов. Она используется только как проверка возможности короткого пути в имеющейся топологии, никогда для подтверждения доступности или сокращения интервалов. Если короткий диагностический путь существует, площадка остаётся для разбора. Если путь вовсе не найден в пределах 15 км, отсутствие пути не приравнивается к доказанному длинному подъезду.

Исключение относится к модели OSM, а не является доказательством отсутствия короткого подъезда на местности. Неполнота OSM, ограничения регионального среза и ошибка координаты могут менять результат. Диагностическая привязка допускает 200 м, чтобы не исключать неясный случай только из-за порога 60 м. До реальных въездов на территорию площадок маршрут по-прежнему не проверен.

AFIR задаёт расстояние до зарядки ≤3 км от ближайшего съезда; предел возврата ≤3 км и привязка ≤60 м — дополнительные условия пилота. Цветные интервалы не являются заключением о соответствии AFIR. Полная длина интервала учитывает возврат предыдущей площадки, движение по A5 до следующего съезда и подъезд следующей. Расчёт не обнуляется на каждой развязке; разделение на участки используется для проверки съездов.

130 — число узлов разрешённых ответвлений, не число именованных развязок. У одной развязки может быть несколько рамп. Названия и тип площадки отдыха дополняют проверку топологии, но не служат обязательным условием поиска. Часть безымянных ответвлений может не иметь метки площадки отдыха; они всё равно включены.

Участок Friedberg → Bad Homburger Kreuz: три быстрые DC справа (Edouard-Desor-Str. 4, Im Dammwald 5, Rohrwiesenstr. 4) исключены в направлении Basel по длине подъезда. Съезд на Spießwald (node 60013734) сохранён в поиске. Замкнутая парковочная петля не превращается в связь с соседними улицами.

Данные A1/A9 побайтово совпадают с предыдущим обновлением. Обычный режим карты, фильтры и кластеризация не изменены. Изменение визуального различия точек/обводки остаётся отдельной будущей задачей.

## Аудит и воспроизведение

- `data_sources/a5/exit-zones.json`: результат по каждому кандидату, строгий маршрут, диагностическая нижняя проверка расстояния и все ответвления.
- `exit-zones-audit.json`, `pilot-3km-audit.json`: сводки.
- `pilot-3km-site-review.csv`: все площадки, включая скрытые.
- `exits.csv`, `exits.geojson`: узлы всех учтённых ответвлений для проверки, в том числе QGIS.
- `exit-sections.json`: непрерывные участки направления между всеми последовательными ответвлениями, включая промежуточные площадки отдыха.

Полная сеть находится в ранее выданном `a5-road-access-diagnostics.zip`; в браузер и это обновление она не включена.

```bash
python scripts/a5_exit_zones.py --network /path/to/access-network.json
python scripts/prepare_motorways.py --route A5
python scripts/export_a5_exit_review.py
```
