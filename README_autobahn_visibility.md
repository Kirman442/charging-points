# Видимость площадок в режиме автобана

Обновление поверх `charging-points-a1-road-access.zip`. Распаковать в корень проекта в dev и выполнить `npm run build`, затем `npm run preview`. Повторно скачивать или готовить дорожную сеть не требуется.

По умолчанию показывается только линия A1/A9. В поле «Площадки на карте» доступны:

- Не показывать — только линия.
- DC ≥150 кВт · маршрут найден — только быстрые площадки с найденными подъездом и возвратом.
- Все DC-площадки ≥150 кВт — включая кандидатов без найденной связи.
- Все кандидаты в коридоре — также площадки меньшей мощности.

Светлые точки — кандидаты без найденного дорожного маршрута; они не обязательно имеют DC ≥150 кВт. Бирюзовые — маршрут найден, фактический въезд ещё не подтверждён.

Площадки вне коридора по умолчанию скрыты. Их можно включить отдельно, сняв соответствующий флажок. При отдалении радиус точек уменьшается: около zoom 6 — 1 пиксель, при приближении до zoom 12 — 4 пикселя. Числовые индексы и клики сохраняются.

Если открыть площадку из списка при режиме «только линия», появляется одна выбранная точка и её карточка. Возврат к аналитике скрывает эту точку. Показ площадок не меняет рассчитанные интервалы или показатели справа.

Проверки: 67 JS-тестов, lint и сборка прошли; Chromium проверил режимы показа, A1/A9, карточки и сброс, ошибок JavaScript нет. Подготовленные Parquet и расчётные связи не изменены.
