# Отображение площадок A1 / A9

Обновление поверх dev, базовый коммит `77232cd`.

- По умолчанию видны все площадки с найденным подъездом и возвратом для выбранного направления, независимо от мощности.
- Обводка выделяет участников расчёта: найден маршрут, суммарная мощность ≥400 кВт и минимум одна DC-точка ≥150 кВт. Въезды остаются непроверенными.
- Чекбокс «Показать кандидатов без найденного маршрута» в правой панели добавляет светлые точки. Интервалы не пересчитываются.
- При отдалении точки уменьшаются, при приближении увеличиваются: радиус от 0,8 до 7 пикселей. Область выбора мышью сохранена.
- Открытие кандидата из списка показывает выбранную точку даже при выключенном чекбоксе. Закрытие карточки возвращает обычный режим показа.
- Сброс отключает кандидатов без найденного маршрута. Фильтры инфраструктуры по-прежнему влияют только на отображение.

## Установка

Распаковать архив поверх проекта в ветке dev.

```bash
npm run build
npm run preview
```

Проверки: 70 JS-тестов, lint, сборка и Chromium (A1/A9, оба направления, раскрытие методики, статусы списка, чекбокс, неизменность интервалов, карточка и сброс).

## Панели и статусы

Пояснения перенесены из левой панели в правый блок «Методика и пояснения», закрытый по умолчанию. Легенда и основные показатели остаются видимыми. В DC-списке отдельно подписаны «Маршрут найден · въезд не проверен» и «Маршрут не найден». Размеры точек сохранены: масштабирование уже работает, дополнительных изменений не потребовалось.
