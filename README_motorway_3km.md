# A1, A5, A9 — общая методика пилота

Обновление поверх dev `77232cd` и обновления панелей от 7 октября 2026. Добавляет A5 в переключатель; пояснения остаются в закрытом блоке правой панели.

## Критерии

- Подъезд по дорожной сети от точки отделения съезда: ≤3 км.
- Возврат на своё направление: ≤3 км. Это дополнительное условие пилота, не норматив AFIR.
- Координата площадки до ближайшей дорожной геометрии: ≤60 м. Это техническая настройка, не норматив AFIR.
- Найденный маршрут не подтверждает въезд на территорию; проверенных вручную въездов нет.
- В расчёте интервалов участвуют только площадки, прошедшие условия пилота, с суммарной номинальной мощностью ≥400 кВт и DC-точкой ≥150 кВт. Номинальная сумма не гарантирует одновременно доступную мощность.
- Данные и режим предназначены для анализа легковых автомобилей, не оценки грузовых зарядок.

AFIR Article 2(3)(a): 3 км относятся к одному пути от ближайшего съезда до зарядки. Отдельного численного предела возврата эта норма не задаёт. Разъяснения Еврокомиссии 4.10–4.11 и 4.15–4.19:
https://transport.ec.europa.eu/transport-themes/clean-transport/alternative-fuels-sustainable-mobility-europe/alternative-fuels-infrastructure/questions-and-answers-regulation-deployment-alternative-fuels-infrastructure-eu-20231804_en

## Интервалы

Длина = возврат предыдущей площадки + длина автобана от её фактической точки возвращения до съезда следующей + подъезд следующей площадки. Цвет линии определяется этой полной длиной, а геометрия отображает участок автобана между съездами. `road_gap_km` хранит длину линии, `gap_km` — полный дорожный интервал.

Площадки с одинаковым съездом рассматриваются вместе; для пары групп выбирается минимальная совместимая дорожная длина. Если предыдущий возврат находится дальше следующего съезда по ходу движения, такую пару не используем. Если совместимой пары нет, интервал неизвестен: отрицательные расстояния и искусственные связи не создаются. Края маршрута неизвестны; разрыв A1 в Эйфеле не соединяется.

Порог 50 км — предупреждение пилота. Цветные интервалы и показатели не являются заключением о соответствии AFIR: необходимы подтверждение въездов, публичного доступа, мощности, категории TEN-T, применимой даты и исключений.

## Пересоздание

Установить Python-зависимости из `scripts/requirements-a9.txt` (дополнительно networkx, если отсутствует).

```bash
python scripts/prepare_motorways.py
```

Повторный поиск A5 по полной сети из ранее выданного диагностического архива:

```bash
python scripts/refresh_a5_access.py --network /path/to/access-network.json
python scripts/prepare_motorways.py --route A5
```

Полная сеть A5 не включена в браузер и этот небольшой архив обновления. Она находится в отдельном `a5-road-access-diagnostics.zip`. Хэш сети проверяется перед поиском. Для пересоздания A1/A9 используются прежние проверенные связи; для нового поиска нужны соответствующие полные сети и параметры `--network` старых подготовительных скриптов. Их CLI завершается применением общей новой политики.

Обновлять три Parquet и исходники вместе: декодер отвергает прежнюю политику 10 км и устаревший формат. Чекбокс меняет только видимость кандидатов, интервалы не пересчитывает.
