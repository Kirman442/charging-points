# Обновление панели A1 / A5 / A9

Распаковать архив в корень проекта с заменой двух файлов интерфейса.

Панель показывает площадки с найденными подъездом и возвратом, вложенные группы по мощности, число площадок для проверки, чекбокс и максимальный интервал. Пояснения и исключённые площадки находятся в закрытом блоке «Методика и пояснения». Служебные списки ответвлений и быстрых DC убраны из панели; исходные данные сохранены. Все числа зависят от выбранного направления.

Повторный анализ съездов A1 и A9 выполнен в обновлении 30_step. Оба направления используют общий отбор по дорожным подъездам и возвратам от всех ответвлений. Воспроизводимый запуск и сведения о сети описаны в README_a1a9_exit_zones.md.

## Получение данных Overpass

Вставить содержимое scripts/overpass_a1_access.ql в Overpass Turbo и экспортировать результат как исходный OSM JSON, например a1-access-network.json. Для A9 — scripts/overpass_a9_access.ql и a9-access-network.json. Это два отдельных запуска; обе стороны трассы выгружаются вместе. Направления будут проверяться отдельно алгоритмом.

Запросы собирают основные проезжие части по route relations и ref, окружающие дороги, промежуточные съезды и подъезды к площадкам отдыха, узлы с их тегами и ограничения поворотов с полными участниками. Дороги с запретами не удаляются при выгрузке: запреты оценивает модель. Данные не подтверждают наличие реального въезда.

Коридор выгрузки 5 км — запас для поиска дорожных путей до 3 км от трассы, а не условие AFIR или допуска площадки. Для расширенной диагностики за пределами этого коридора могут понадобиться дополнительные данные. Сам радиус не гарантирует полноту OSM, корректность тегов или связность сети.

A1 и A9 длиннее A5; публичный сервер может отказать из-за объёма, памяти или времени. Не уменьшать коридор для обхода отказа: сохранить текст ошибки, затем разделить выгрузку на перекрывающиеся участки или использовать региональные PBF. Ответ с remark/runtime error не считать полной выгрузкой.

Синтаксис сверён с официальной документацией Overpass QL: https://wiki.openstreetmap.org/wiki/Overpass_API/Overpass_QL . Большие серверные выгрузки при подготовке запросов не запускались.

## Проверка интерфейса

ESLint и production build прошли. Панель отрендерена с реальными данными всех шести направлений A1/A5/A9; проверены вложенные числа DC, закрытый блок пояснений и отсутствие двух служебных списков. Для A5 на север: 432 с маршрутом, 235 для проверки, быстрые DC 171 = 132 + 39. На юг: 389, 196, быстрые DC 155 = 123 + 32.
